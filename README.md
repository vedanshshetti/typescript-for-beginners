# typescript-for-beginners
A simple repository teaching people moving from JavaScript to TypeScript all the basics, e.g. how to define types, how to apply them, etc.


## How to get started

1. Clone the repository and open it in the IDE of your choice.
2. You will find some folders with the lesson material. Every
   lesson is named as "[number]-[topic]", letting you easily 
   go to the correct lesson.

## Prerequisites
 - JavaScript Fundamentals
